# 首次运行没有凭据时起来、进配置流程，不退出

> 状态:implemented · 提出 2026-08-31 · 拍板 2026-08-31 · 落地 `59989b1` · **2026-09-01 被 [配置是运行态](2026-09-01-config-is-runtime-state.md) 与 [首次运行走引导设置](2026-09-01-first-run-guided-setup.md) 细化**（那一版是启动前一屏向导）· 来源 [产品级 TUI 设计方案](../../design/tui.md) §九 D1（2026-09-08 从那张表转录成条）

## 决定

终端里有人坐着、没有凭据 → 起来、进配置流程，而不是退出；配置流程跑在 `createEcho()` 之前。管道 / CI 保持退出码 1。

## 理由

终端有人坐着就问；没人坐着（管道 / CI）报错退出。原 TUI 设计稿「待拍板 1」。

## 落地

`59989b1`。之后 D3 把「配置」从启动前一屏改成运行态、D4 把首次运行改成引导设置，本条只剩「不退出」这一半仍是现状。

## 验收

终端下没有凭据启动 `echo-agent` 不以退出码 1 结束、进入配置流程；stdin 重定向时退出码 1。
